## 🚀 How to Use the Repository

1. Open any algorithm folder  
2. Start the `.ipynb` notebook  
3. Run the cells step-by-step  
4. Tweak values → observe changes  
5. Understand how ML truly behaves  

This repo is interactive, intuitive, and ideal for strong ML foundations.
